# ETC 2026 — Références HTS / HCS

Page publique regroupant les références citées dans l’atelier consacré à la
qualité des données, à la normalisation, à la sélection des hits et aux
spécificités du High-Content Screening.

## Pages publiques

- Bibliographie : https://cedrichk.github.io/ETC2026/
- Vote anonyme : https://cedrichk.github.io/ETC2026/vote.html
- Tableau de bord formateur : https://cedrichk.github.io/ETC2026/admin.html

Le tableau de bord génère un code distinct pour chaque séance. Les
participants utilisent toujours le même QR code. Les réponses ne contiennent
ni nom ni courriel ; elles sont transportées par des topics aléatoires et
éphémères sur le serveur public `ntfy.sh`.

Les questions sont pilotées une par une : sélectionner le QCM correspondant à
la diapositive, ouvrir le vote, le fermer, puis révéler la correction. Le
bouton **Nouvelle séance** crée un nouveau code et remet les compteurs à zéro
pour le groupe suivant, sans mélanger les résultats.
